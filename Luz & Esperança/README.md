# Luz & Esperança — Setembro Amarelo

Projeto acadêmico de UX/UI com foco em acolhimento, valorização da vida e acessibilidade.

## Tecnologias

- HTML5 semântico
- CSS3
- JavaScript
- Web Speech API
- ARIA
- Layout responsivo

## Recursos de acessibilidade

- Modo de alto contraste
- Aumento e redução do tamanho da fonte
- Leitura das mensagens por síntese de voz
- `aria-label`, `aria-live`, `aria-pressed` e landmarks semânticos
- Navegação por teclado com foco visível
- Texto alternativo e conteúdos em formato textual
- Suporte a `prefers-reduced-motion`

## Como executar

Abra o arquivo `index.html` em um navegador moderno.

Não é necessário instalar dependências ou utilizar servidor.

## Estrutura

```text
luz_especial/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Observação

O conteúdo religioso é apresentado como mensagem de acolhimento e esperança. O projeto não substitui atendimento médico ou psicológico.

Em situações de sofrimento emocional, o projeto apresenta o CVV pelo telefone 188. Em risco imediato, procure um serviço de emergência ou alguém de confiança.
